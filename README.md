# TD-DFT for QM7 Molecules

This is a work-in-progress project.

This project aims to create a database storing information about QM7 molecules. A user can access TD-DFT information about any molecule in the QM7 dataset. There will be a UI that allows for easy access of information.
Here is an example subset of Gaussian output files: https://drive.google.com/drive/folders/17ctwWLqeghYEt07i_sEI_GGfONWgqJW-?usp=drive_link. The full database will be hosted on one of the linux machines owned by the Jesus group.
